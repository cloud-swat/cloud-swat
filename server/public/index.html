Cloud SWAT turns Claude Code subagents into a visible team. Each one gets a name, a role and a live card showing what they search, read, fix and find.

See the demoInstall the plugin

How it works

1

Install the plugin

Add the crew skill, five specialist agents and the live-reporting hooks to Claude Code.

2

Link your device once

Start Claude Code. Your browser opens, you sign in with GitHub or Google and approve. No keys to copy.

3

Watch the mission live

Say “use the crew to…”. The live view opens on its own and every agent's work appears as it happens.

Install

# in Claude Code
/plugin marketplace add cloud-swat/cloud-swat
/plugin install cloud-swat@cloud-swat

# restart Claude Code. A link to connect this device opens in your browser.
# then just ask:
use the crew to audit this repo for security issues

Also inside Claude

Ask about your crew

Connect Cloud SWAT as an MCP connector and ask “how many tokens did my crew use this week?”

Built to save tokens

Live tracking runs in hooks outside the model, so it costs zero tokens. The MCP has 4 small tools with one-line answers.
